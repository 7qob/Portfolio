Stuff I use

Tools
  • VS Codium My main editor — all of VS Code, without the telemetry.
  • Flow Launcher Keyboard launcher I use to open apps and files in a keystroke.
  • i3wm Tiling window manager that keeps my Linux workspace keyboard-driven.
  • Glaze WM Brings that same i3-style tiling over to Windows.
  • Windows 11 Daily driver for everything outside the homelab.
  • Alacritty Fast, minimal, GPU-accelerated terminal emulator.
Techstack
  • TypeScript The backbone of most of my web work — I type everything from the frontend down to the API so the compiler catches mistakes before they ship.
  • Rust My pick when speed and correctness really matter — it's what modd is built in, and the borrow checker keeps the whole thing honest.
  • React My go-to for building interactive interfaces — component-driven UIs that stay manageable as a project grows.
  • Node.js / Express Lightweight APIs and backends behind my apps — quick to stand up and easy to keep small and readable.
  • Python My duct tape for quick scripts, automation, and the glue code around AI models and experiments.
  • Raspberry Pi The little always-on server my projects live on — cheap, low-power, and surprisingly capable as a home backend.
  • Docker Keeps every service isolated and reproducible, so I can tear something down and bring it back exactly the same.
  • Cloudflare Tunnels Exposes my self-hosted apps to the internet without opening a single port on my network.
  • self-hosting A bit of a philosophy for me — I'd rather run and own my services than rent them from someone else's cloud.
