Kobui

  • React
  • TypeScript
  • Vite
  • KoboldCpp

A local, privacy-friendly alternative to cloud-based AI character services — a React chat frontend that talks to a KoboldCpp server running on your own machine.

Running it

  1. Install KoboldCpp and download a GGUF model.
  2. npm install, then npm run dev.
  3. Point the KoboldCpp URL at http://localhost:5001 in settings.
  4. Open http://localhost:5173.

Models it runs on

Documentation ships with the app — in settings, or directly at /docs. Nothing leaves the machine: the frontend only ever talks to your own KoboldCpp instance.
Claude assisted with component architecture, CSS Modules, TypeScript and the KoboldCpp integration. All generated code was reviewed and adapted; the design and feature decisions are mine.
